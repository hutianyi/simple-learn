# 简单学 · SimpleXue

一个使用 SwiftUI 编写的本地 iPad 学习 App，将单词记忆、错题复习、语音默写、心算练习、英文听读和图文阅读整合到同一入口。

当前 iPad 正式版本为 **[3.0.1（构建 65）](https://github.com/hutianyi/simple-learn/releases/tag/v3.0.1)**，支持 **iPadOS 27 及以上**。简单读改用玫瑰红，简单练沿用暖橙色。首页入口与模块内控件均采用各自的主题色。

[简单读安卓电视版](简单读%20-%20安卓电视版/README.md)是同仓库下的独立 Android 工程，目前为 **0.1.2**。它和 iPad 简单读使用相同的阅读包格式，各自保存进度并独立编号。

## 功能

| 模块 | 主要功能 |
| --- | --- |
| 简单记 | 单词导入、双向卡片复习、FSRS 间隔复习、Apple Pencil 英文默写、学习统计与 JSON 备份 |
| 简单练 | 多选 TXT / JSON 错题文件导入、练习与订正、求助 ChatGPT 复制提示词、间隔复习、未完成会话恢复、题库备份 |
| 简单默 | 中英文词语朗读、重读、自动切词、倒计时与数据恢复 |
| 简单算 | 加减乘除及混合心算、练习计时、成绩与历史统计、数据恢复 |
| 简单听 | 粘贴 Markdown 文章、系统英文语音连续朗读、四档语速、播放顺序、循环与 Sleep Timer |
| 简单读 | KET 阅读、阅读包导入、未读与已读文章列表、图文翻页与字号、选择题本地判题、阅读与答题进度、完整备份 |

简单背已隐藏首页入口，原有课文、设置和备份仍保留；本文下方的简单背说明作为已有数据与历史功能参考。

在首页选择功能，点击左上角“简单学”返回首页。简单练做题、核对和订正途中均可切换，退出前保存进度，再次进入自动回到未完成的题目和阶段；也可点“稍后继续”返回简单练的今天页。简单听播放或暂停时须先停止。

简单记的“学习／词库／统计／设置”、简单算的“练习／统计”和简单练的“今天／题库”统一使用固定底部图标加文字按钮，不显示顶部系统标签栏。当前页面以模块强调色标示，各主页面可直接切换并保留各自状态，简单记不再需要先点左上角返回才能切换。词条详情等页面内部仍保留返回操作；简单记正式复习、额外加练、默写和简单练做题期间隐藏页面切换按钮，保持原有学习流程。

界面使用共用的主次按钮、标题与页面边距规范。六模块集中维护浅色、深色和增强对比度强调色，按钮文字随外观调整；判题状态与统计图配色保留原规则。首页今日任务移除外层底板，状态位于卡片标题行，窄窗口或辅助功能大字号时改为单列；全部功能入口使用横向图标与名称、中性卡片底色，保留拖动排序。简单记完成卡片复习后按实际任务提供“继续复习”“继续今天的默写”或“完成，返回”；下一项检查只预览默写队列，不创建学习任务。简单听的导入文章和设置位于文章库工具栏，窄窗口中可先返回“文章库”操作。简单背开始练背诵后自动收起朗读顺序与语速设置，可展开查看；提示程度、下一步、暂停和重听始终直接可用。

首页六个功能卡片支持长按拖动排序：按住卡片后拖到其他卡片的位置，其他卡片自动让位，松手完成。顺序保存在当前设备上，切换功能或重新打开 App 后仍保留；VoiceOver 可通过“向前移动／向后移动”操作调整顺序。

简单记支持录入 `conversation n.对话`：英文保存为 `conversation`，卡片释义显示 `n.对话`，词性标识不参与英文默写。支持 `n.`、`v.`、`adj.`、`adv.` 等常见标识，以及单条添加、批量导入和词条编辑；已有词库不会自动改写。

简单记当天全部任务完成后，单条添加或批量导入的新单词从次日开始安排双向卡片复习，保留今天的完成状态和连续打卡。当天尚未全部完成时，新增单词仍按原规则加入当天的卡片复习。

简单记的新词在两个不同学习日的中文→英文正式卡片复习首次回答均为“认识”后，直接进入每日默写，不再要求先抄写三遍。每天最多新安排 5 个词，与到期词共用每日默写上限，积欠和到期复习优先；旧词摸底仍按原规则安排。默写错误时才进行三遍正确抄写及重默，全部必要步骤完成后只显示结果和“返回首页”。当天已经完成的队列不会因为出现新合格词而重新打开，未安排的新词留到后续学习日；主动修改每日上限仍按原规则调整当天队列。旧版首次抄写尚未完成的词可直接参加默写，已完成抄写的词保留原来的复习日期，既有成绩与备份继续兼容。

简单记的每日默写上限修改后当场调整当天尚未作答的任务，保留已经作答的结果及订正进度。“连续完成天数”要求当天到期卡片全部复习一遍、默写完成，并完成错词抄写和重默；某类没有任务视为该项完成，两类均无任务且没有实际学习时不计入。今天尚未完成时保留截至昨天的连续天数；旧版历史按当天已完成的正式复习会话、默写及订正记录兼容认定，不覆盖新版严格完成记录。统计页顶部展示近一年学习热力图，浅紫色表示有学习记录，深紫色表示全部完成，其余九项统计按 3×3 排列。当天严格完成后自动显示礼花庆祝、鼓励语及刚点亮的热力图和连续完成天数；同一天只自动庆祝一次，并等待最后答题反馈或核对结束，系统减少动态效果设置开启时不播放礼花。

到期默写按“以前积欠优先、当天任务随后”的顺序共用每日上限，不额外增加额度。例如上限 50 个、积欠 30 个、当天到期 30 个，则当天安排积欠 30 个及当天 20 个，剩余 10 个次日优先安排。完成当天额度及全部订正后，还会检查队列之外是否仍有以前到期但未完成的默写；仍有积欠时不认定今日全部完成，也不自动庆祝。仅当天超出额度、尚未安排的词不阻止当天完成，之后补完积欠不会追改之前的每日完成记录。

简单算的统计页顶部展示近一年口算热力图，按当天所有题型、所有已完成批次的答题数累计，答错也计入，题数越多紫色越深；点格子可查看当天题数。每天有已完成批次的答题记录就计入连续练习，今天尚未练习时保留截至昨天的连续天数。每批练习在最后答题反馈结束且保存成功后都展示礼花、鼓励语、本批和当天累计题数、连续练习天数及热力图，同一天可多次庆祝；系统减少动态效果设置开启时不播放礼花。未完成批次不计入；跨午夜的已完成批次按每道题的实际作答日期统计，删除历史或恢复备份后按现有记录重新计算。

简单算的累计数据在“平均用时”旁显示“最近三次平均用时”：选取当前筛选题型最近三次已完成练习，将其中对应题目的总用时除以题数，不足三次时按已有记录计算。混合筛选沿用全部题型统计。正确率和平均用时折线图、简单记的最近正式复习正确率柱状图支持按住查看日期和具体数值，移动手指可切换记录，松手后提示消失。数值气泡固定显示在对应数据点或柱子上方，图表预留顶部空间；气泡使用模块主题纯色底色和紧凑布局。

简单记和简单算的庆祝页出现时播放一次约 1.5 秒的上扬铃声音效；普通统计页不播放，关闭庆祝页、切换功能或进入后台时停止。

简单记和简单算各自按周末规则计算打卡：周六或周日任一天达到该模块原有完成标准，周末两天都计入完成记录、热力图及连续天数。周六完成时，周日到来后自动计入；周日完成时自动补上周六，不要求加倍补学。周末完成后的庆祝页显示“周末完成一天，两天都算打卡成功！”和“另一天可以放心休息啦。”，平日不显示。周日尚未完成时暂时保留截至周五的连续天数，周末两天均未完成则到周一中断。实际作答日期、题数和学习任务仍按原规则保存；周末打卡根据保存的完成记录计算，备份恢复及删除记录后同步重算。

简单记、简单算和简单练各自判断周末完成状态，互不代替：周末任一天达到该模块的完成标准，周日该模块显示“今日已完成”；尚未完成的模块继续显示自己的任务。组合不限，例如周六只完成简单算或简单练，周日简单记仍显示待复习、待默写；只有简单记完成时，简单算仍显示“今日待做40题”。进入周末已完成模块后不再显示复习、默写或练习入口；原有内容保留，周一恢复按任务显示。简单练只读取已保存的完整练习及订正状态，不改写复习日期、掌握次数，也不加入简单记和简单算的连续天数或零花钱奖励。

简单记和简单算的庆祝页顶部展示零花钱提醒，各自按连续完成天数计算：每连续 7 天可找爸爸兑换一次 3 元零花钱。平时显示连续天数及距离下一次兑换还差几天，第 7、14、21 天等突出展示“把这个页面给爸爸看，领取你的奖励吧”。补做或周末打卡跨过奖励门槛时也会提示，例如从 6 天跳到 8 天或 9 天，仍显示已达成连续 7 天、可兑换 3 元，并保留实际连续天数和下一次奖励倒计时。同一天多次庆祝使用相同的奖励提示；补上漏做那天恢复的连续天数也计入，连续中断后从新的一轮开始。页面仅提示兑换，不记录实际领取状态。

简单记和简单算支持补上漏做一天的打卡：平日仅在昨天未完成、前天已有连续记录时，进入模块询问一次。周六、周日共用一次学习机会：周五漏做且周四已有连续记录时，可在周六或周日选择补上；周日补完周五并完成当天任务后，周五、周六、周日一起计入完成，接回原有连续记录。仅周六没做时，周日正常完成即可覆盖周末，不额外补学。选择补上后仍须在当天跟随一轮完整学习流程，完成并保存后恢复连续天数。简单算使用当前正常批次的题型和题数，题量翻倍（默认 40＋40＝80 题）；简单记选择补上或放弃连续记录都使用相同的正常学习任务：卡片复习包含全部到期和逾期内容，没有数量上限；默写合并到期和逾期词，按设置的每日上限安排，超出的留到后续日期，不额外添加巩固任务。旧词摸底也遵守设置的上限，选择不限时仍每天最多 50 个。选择补上仅在完成今天的正常任务后恢复漏做那天的打卡，并自动衔接卡片、默写和订正。拒绝或主动结束后不再询问这一次中断；跨天未完成则机会结束；同一次缺口在周六拒绝或开始后未完成，周日不再提供第二次机会。除上述周末衔接外，连续漏两天及以上不提供补学。临时切到后台或锁屏不算主动结束。热力图标明“补学完成”，实际作答仍按真实时间统计；主动结束补学时保留已保存的卡片和默写回答、以及口算已答题记录，未完成口算不计入连续练习。补学结果和已处理的机会随模块及整体备份保存，旧备份仍可读取。

简单默只以换行和制表符拆分条目，词组中的空格、逗号和分号保留。默认按内容长度自动计时：读完两遍后至少留 60 秒，英文超过 10 个字母后每增加不足或满 5 个字母加 10 秒，超过两个单词后每多一个加 10 秒；中文每字加 5 秒，混合内容共用一次 60 秒基础时间，最终向上取整到 10 秒。数字独立成词时计入英文条目词数，撇号保留在单词内。朗读期间暂停计时，剩余 30 秒时提醒并重读；每条最多手动加一次 30 秒，也可提前进入下一条。固定时长仍可在设置中选择，备份与恢复也移入设置。

简单默的设置以弹窗打开，点右上角“完成”即可回到原词单，设置即时保存；备份与恢复仍可从弹窗内进入。

每批默写结束后，按本批朗读顺序逐项核对，默认默对；绿色圆形对勾表示默对，红色圆形叉表示默错，也可点“全对”再修改个别错项。确认结果后，直接重默本批错项；重默结束后可继续核对和重默，直到全对。原始输入词单保持不变，核对结果仅用于当前练习，不写入备份。

简单背选择课文后可直接进入“听课文／练背诵／测一测”。练背诵始终使用全文，保留三档文字提示，可选择系统先读或自己先背；每句双方都完成后才进入下一句。自己先背时手动确认后听系统读同一句，练习不录音、不评分，可在练习页“声音设置”中调整语速；与听课文共用并保存语速，开始练习前调整。练习操作区固定，下面的句子列表从顶部自然显示，当前句推进到中部后才自动滚动并居中，三档提示都支持跟随。设备上已安装的指定声音会自动选用；可在“管理 → 播放与显示设置”中试听与调整。测一测只录音自查：录制期间隐藏原文和侧栏课文预览，手动背完后自动回听并显示全文，由孩子自行核对；可回听、再背一次或结束。取消文字识别与评分，不需要准备识别资源。只保留最近一份完整录音，任意课文开始新录音前删除旧文件，未完成尝试在取消或后台时清理；下次启动清理专用缓存，录音不进备份。录音、自查或清理过程中须先结束本轮才能切换功能。

简单背“听课文”的开始朗读、暂停或继续、上一句、下一句和停止按钮固定在正文下方，当前句、已完成遍数和定时剩余时间随播放操作区显示，滚动长课文时仍可操作。选段、语速、遍数和定时设置保留在正文上方；“练背诵”和“测一测”的布局保持原样。

构建与自动测试已经验证；指定声音、实际录音回听和锁屏连续播放仍需在目标 iPad A16 上试用。SDK 或编译成功不代替实际设备验收。

## 构建与安装

需要一台安装 **Xcode 27 或更高版本**的 Mac，以及运行 iPadOS 27 或更高版本的 iPad。Apple Pencil 默写需要兼容的 Pencil 和真机。

1. 克隆仓库，然后打开 `SimpleXue.xcodeproj`。
2. 选择 **SimpleXue** 方案，在 **Signing & Capabilities** 中选择自己的开发团队。若模块提示缺少 Team，也为该 target 选择同一团队。
3. 首次安装到自己的设备时，将 App 和模块的 Bundle Identifier 设置为自己的唯一标识；后续更新保留同一标识，以保留已有数据。
4. 选择连接的 iPad，点击运行。开发者模式、信任与签名有效期按 Xcode 和设备提示处理。

```sh
git clone https://github.com/hutianyi/simple-learn.git
cd simple-learn
open SimpleXue.xcodeproj
```

仓库提供源代码，需自行构建和签名。工程已生成，首次打开无需 XcodeGen。FSRS 依赖固定到 `4fbaf20184d62f82a9f44f343337c61a2c5483e9`；首次构建时 Xcode 可能需要联网下载依赖。

修改工程生成配置后，可在仓库根目录使用已安装的 XcodeGen：

```sh
xcodegen generate
```

生成工程后需重新选择本机开发团队。个人签名信息不应提交到仓库。

## 数据与迁移

首页上方的「今天的学习」从左至右为简单记、简单算、简单练，分别显示待复习卡片数和按当前默写队列计算的待做单词数、简单算默认待做 40 题或今日已完成、待练与待订正题型。未完成的小卡片更醒目，已完成的变淡并显示勾选；三项都完成后显示庆祝卡片，并分别展示简单记、简单算距离下一轮七天奖励的剩余天数。任一模块当天达成七天奖励时，首页优先展示兑换提醒，不要求其他模块全部完成；仍有未完成任务时保留三项任务卡片。两个模块同时达标时提示各可兑换 3 元、合计 6 元。奖励卡片按内容自然增高，支持文字换行；周末、补打卡和免做卡沿用模块原有奖励计算，页面只提示可兑换，不记录领取。点击小卡片可进入对应模块。返回首页、App 回到前台及关闭整体备份页后会刷新。六模块卡片缩小，为概况留出空间。

首页右上角的“备份与恢复”可一次导出所有模块的完整备份，包括新增简单读和隐藏的简单背。简单读的正文、插图、各内容版本和阅读答题记录随备份保存。文件包含已保存的学习内容、记录、进度和设置，不含简单背录音、临时缓存和系统语音资源；空模块也纳入备份。完成系统“存储到文件”后才记录成功导出时间。

整体恢复先校验全部模块，再确认替换备份包含模块的数据和设置（包括隐藏的简单背课文库）。恢复不含简单读的旧版整体备份时，保留当前简单读内容和进度；其他必要模块缺失仍会拒绝恢复。恢复前在 `SimpleXue/WholeBackup` 保留安全副本；若当前模块损坏、无法导出有效数据，先原样保留该模块文件（含数据库辅助文件）和设置，再从通过校验的整体备份恢复。无法完整保留原数据时停止恢复；失败时自动回退。若恢复中断，下一次启动会先完成回退，再开放学习入口。回退未完成时可重试，安全副本应保留。App 本地安全副本不能替代外部导出的备份。简单算和简单练已隐藏模块顶部的“数据”入口，日常备份与恢复统一使用首页入口；其他模块的原有备份入口继续保留。

简单练禁止删除未完成练习正在使用的题库，完成练习后可删除；旧版遗留的空会话会在进入模块时清理。全部扩展题停用的题型显示“缺少可用题目”，不计入可开始练习的任务，支持进入题目详情重新启用。

简单练在“题库 → 批次 → 题型”中展开题目后显示完整题干、答案及解析，长题目可向下滚动查看。“原错题”下方提供“复制原错题”按钮，无需展开即可将完整题干的 Markdown 原文复制到剪贴板，并显示成功提示；复制内容仅含题干。

简单练的扩展题可以循环复用，无需因为反复答错而重新准备整套题库。正式练习按当前阶段优先选择近似题或迁移题，在对应题池中先出未见题，全部见过后优先复用最久没出现的题。订正先选本轮没用过的可用近似题，用完后也按最久未出现的顺序循环；只有一题可用时允许再次使用。原题和已停用的题不参与循环；没有可用近似题时仍提示补充题库。每次作答单独保存，订正不计入掌握次数，连续订正三次未通过仍转入“需要讲解”。

简单练核对时标记为“做错了”的题目及订正页的错题卡片提供“求助 ChatGPT”：点击后将该题原文和引导提示词复制到剪贴板，并显示复制成功提示。打开 ChatGPT 粘贴发送后，可让孩子跟着每次一个小问题逐步思考；提示词要求先了解孩子的想法、按需给提示，不直接提供答案或完整解法。复制内容不包含题库中的参考答案和解析。

词库、题库、文章、学习进度和设置保存在设备本地。项目不提供账号系统、广告、分析服务、云同步或付费 AI API；系统语音下载及首次依赖下载可能需要网络。

原五个模块支持导出和恢复；恢复会替换对应模块数据。恢复前先结束当前学习，保存外部备份，恢复后核对记录数量、进度和设置。容器内的安全副本不能替代外部备份。

简单听可在“设置 → 备份与恢复”导出全部文章、原文、导入顺序和播放设置，恢复前需停止播放与定时。恢复会替换文章库及备份中的播放设置，并自动保留恢复前的安全副本；也兼容仅含文章库的旧内部副本。正常保存后，内部安全副本保留最近 10 份，外部导出的备份不受影响。

简单算切到后台时暂停答题计时，包括答题反馈期间自动进入下一题的情况。简单练跨天继续时，下一次复习按实际判定或完成订正的日期计算，原开题日期保留；恢复备份前会校验题号、状态、日期及记录关联，异常备份不会替换现有数据。

简单背采用追加导入：确认预览后追加新课文，重复跳过，冲突保留当前课文；备份设置仅在明确勾选时使用。备份不包含录音。

- **简单记**：使用旧 App 导出的完整 JSON 备份，在模块设置中恢复。
- **简单练**：使用旧 App 数据页导出的 JSON，在模块数据页恢复。
- **简单默／简单算**：从 Xcode 的 Devices and Simulators 下载旧 App 的 `.xcappdata` 容器，再用下列只读工具制作迁移 JSON。

以下命令在仓库根目录运行，假设容器已保存到桌面。工具读取容器并新建 JSON；同名输出已存在时拒绝覆盖。

```sh
python3 Scripts/export-legacy-data.py --module mo --container "$HOME/Desktop/简单默.xcappdata" --output "$HOME/Desktop/简单默迁移.json"
python3 Scripts/export-legacy-data.py --module suan --container "$HOME/Desktop/简单算.xcappdata" --output "$HOME/Desktop/简单算迁移.json"
```

容器和迁移文件包含个人学习数据，请存放在私人位置。迁移验收完成前保留旧 App 与备份。

## 免做卡

首页每周提供一张免做卡，按北京时间计算：周一至周四可以手动使用；本周未手动使用时，周五零点自动用于周五，无需点击或确认。周五没有打开 App，之后打开也会自动计入该周周五，不转移到其他日期、不累计成额外卡。自动使用从升级后的首次打开启用：首次打开在周五及之前，从本周周五开始；在周末则从下周周五开始，不补记启用前的周五。手动使用时，简单记和简单算当天都已完成则不消耗卡；已开始补学时，须先完成或结束补学。

手动使用前会确认，周五自动使用无需确认；使用后不可撤销。简单记和简单算当天计入打卡、连续天数和每连续 7 天的零花钱奖励，日历标注“免做卡”，不增加虚构的题数、正确率、学习时长或单词熟练度。每张卡仅覆盖使用日期，周五自动使用不补周四；当天仍可进入各模块自愿学习。

未完成的简单记复习、默写和订正，以及简单练任务保留到后续日期；次日与到期任务一起按现有规则安排，默写继续遵守每日上限、积欠优先。周五使用时，任务从周六继续安排，周末打卡规则不变。简单算当天免做，次日仍正常显示待做 40 题。

免做卡是首页的共享记录，包含自动使用的起始日期，重新打开不会重置。记录随“备份与恢复”中的整体备份保存并参与恢复失败回退；模块单独备份不包含免做卡记录。恢复没有免做卡字段的旧整体备份时，保留当前免做卡记录。


简单读的独立核心测试可运行 `python3 Scripts/run-du-validation.py`，覆盖阅读包安全校验、多篇拆分、导入更新、答题及进度、分页文字完整性和备份兼容。当前机器没有可运行的 iPad 模拟器，真实 iCloud 文件选择、触控翻页与版面仍需目标 iPad 验收。

运行完整 iPad 测试需要 iPadOS 27 模拟器或真机。核心测试和编译通过不能代替 Pencil 识别、系统声音、锁屏续播、Sleep Timer、横竖屏和真实备份恢复的设备验收。

## 项目结构

- `App/`：App 入口、首页、图标和配置。
- `Shared/`：模块切换、音频协调与数据迁移界面。
- `Modules/`：七个模块及各自测试；首页显示六个入口，简单背隐藏。
- `Tests/`：共享核心测试和界面测试。
- `Scripts/`：本地验证与旧容器只读导出工具。
- `project.yml`、`SimpleXue.xcodeproj`：工程生成配置和已生成工程。
- `Attributions/`：来源说明、原许可证和接入时文件哈希。
