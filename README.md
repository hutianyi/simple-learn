# 简单学 · SimpleXue

一个使用 SwiftUI 编写的本地 iPad 学习 App，将单词记忆、错题复习、语音默写、心算练习、英文听读和课文背诵整合到同一入口。

当前正式版本：**1.4（构建 15）**。仅支持 **iPadOS 27 及以上**。

[1.4 正式版](https://github.com/hutianyi/simple-learn/releases/tag/v1.4)新增首页六个功能卡片长按拖动排序，并在当前设备自动保存顺序，保留补打卡、零花钱提醒、六个模块及整体备份与恢复；此前的五模块公开版本归类为 [0.9 预览版](https://github.com/hutianyi/simple-learn/releases/tag/v0.9)。版本变化见 [CHANGELOG.md](CHANGELOG.md)。

## 功能

| 模块 | 主要功能 |
| --- | --- |
| 简单记 | 单词导入、双向卡片复习、FSRS 间隔复习、Apple Pencil 英文默写、学习统计与 JSON 备份 |
| 简单练 | JSON 错题导入、练习与订正、间隔复习、未完成会话恢复、题库备份 |
| 简单默 | 中英文词语朗读、重读、自动切词、倒计时与数据恢复 |
| 简单算 | 加减乘除及混合心算、练习计时、成绩与历史统计、数据恢复 |
| 简单听 | 粘贴 Markdown 文章、系统英文语音连续朗读、四档语速、播放顺序、循环与 Sleep Timer |
| 简单背 | 中英文课文与古诗、分句选段、循环听读、三档提示、全文逐句练习（系统先读／自己先背）、背诵录音、回听原文自查、课文备份 |

在首页选择功能，结束本轮后点击“切换功能”返回。简单练的未完成会话须先完成；简单听播放或暂停时须先停止。

首页六个功能卡片支持长按拖动排序：按住卡片后拖到其他卡片的位置，其他卡片自动让位，松手完成。顺序保存在当前设备上，切换功能或重新打开 App 后仍保留；VoiceOver 可通过“向前移动／向后移动”操作调整顺序。

简单记支持录入 `conversation n.对话`：英文保存为 `conversation`，卡片释义显示 `n.对话`，词性标识不参与英文默写。支持 `n.`、`v.`、`adj.`、`adv.` 等常见标识，以及单条添加、批量导入和词条编辑；已有词库不会自动改写。

简单记的每日默写上限修改后当场调整当天尚未作答的任务，保留已经作答的结果及订正进度。“连续完成天数”要求当天到期卡片全部复习一遍、默写完成，并完成错词抄写和重默；某类没有任务视为该项完成，两类均无任务且没有实际学习时不计入。今天尚未完成时保留截至昨天的连续天数；旧版历史按当天已完成的正式复习会话、默写及订正记录兼容认定，不覆盖新版严格完成记录。统计页顶部展示近一年学习热力图，浅紫色表示有学习记录，深紫色表示全部完成，其余九项统计按 3×3 排列。当天严格完成后自动显示礼花庆祝、鼓励语及刚点亮的热力图和连续完成天数；同一天只自动庆祝一次，并等待最后答题反馈或核对结束，系统减少动态效果设置开启时不播放礼花。

简单算的统计页顶部展示近一年口算热力图，按当天所有题型、所有已完成批次的答题数累计，答错也计入，题数越多紫色越深；点格子可查看当天题数。每天有已完成批次的答题记录就计入连续练习，今天尚未练习时保留截至昨天的连续天数。每批练习在最后答题反馈结束且保存成功后都展示礼花、鼓励语、本批和当天累计题数、连续练习天数及热力图，同一天可多次庆祝；系统减少动态效果设置开启时不播放礼花。未完成批次不计入；跨午夜的已完成批次按每道题的实际作答日期统计，删除历史或恢复备份后按现有记录重新计算。

简单记和简单算的庆祝页出现时播放一次约 1.5 秒的上扬铃声音效；普通统计页不播放，关闭庆祝页、切换功能或进入后台时停止。

简单记和简单算的庆祝页顶部展示零花钱提醒，各自按连续完成天数计算：每连续 7 天可找爸爸兑换一次 3 元零花钱。平时显示连续天数及距离下一次兑换还差几天，第 7、14、21 天等突出展示“把这个页面给爸爸看，领取你的奖励吧”。同一天多次庆祝使用相同的连续天数；补上昨天恢复的连续天数也计入，连续中断后从新的一轮开始。页面仅提示兑换，不记录实际领取状态。

简单记和简单算支持补上昨天的打卡：仅在昨天未完成、前天已有连续记录时，进入模块询问一次。选择补上后，跟随一轮完整学习流程，完成并保存后一起点亮昨天和今天，恢复连续天数。简单算使用当前正常批次的题型和题数，题量翻倍（默认 40＋40＝80 题）；简单记选择补上或放弃连续记录都使用相同的正常学习任务：卡片复习包含全部到期和逾期内容，没有数量上限；默写合并到期和逾期词，按设置的每日上限安排，超出的留到后续日期，不额外添加巩固任务。旧词摸底也遵守设置的上限，选择不限时仍每天最多 50 个。选择补上仅在完成今天的正常任务后恢复昨天的打卡，并自动衔接卡片、默写和订正。拒绝或主动结束后不再询问这一次中断；跨天未完成则机会结束，连续漏两天及以上不提供补学。临时切到后台或锁屏不算主动结束。热力图标明“补学完成”，实际作答仍按真实时间统计；主动结束补学时保留已保存的卡片和默写回答、以及口算已答题记录，未完成口算不计入连续练习。补学结果和已处理的机会随模块及整体备份保存，旧备份仍可读取。

简单默只以换行和制表符拆分条目，词组中的空格、逗号和分号保留。默认按内容长度自动计时：读完两遍后至少留 60 秒，英文超过 10 个字母后每增加不足或满 5 个字母加 10 秒，超过两个单词后每多一个加 10 秒；中文每字加 5 秒，混合内容共用一次 60 秒基础时间，最终向上取整到 10 秒。数字独立成词时计入英文条目词数，撇号保留在单词内。朗读期间暂停计时，剩余 30 秒时提醒并重读；每条最多手动加一次 30 秒，也可提前进入下一条。固定时长仍可在设置中选择，备份与恢复也移入设置。

每批默写结束后，按本批朗读顺序逐项核对，默认默对；绿色圆形对勾表示默对，红色圆形叉表示默错，也可点“全对”再修改个别错项。确认结果后，直接重默本批错项；重默结束后可继续核对和重默，直到全对。原始输入词单保持不变，核对结果仅用于当前练习，不写入备份。

简单背选择课文后可直接进入“听课文／练背诵／测一测”。练背诵始终使用全文，保留三档文字提示，可选择系统先读或自己先背；每句双方都完成后才进入下一句。自己先背时手动确认后听系统读同一句，练习不录音、不评分，可在练习页“声音设置”中调整语速；与听课文共用并保存语速，开始练习前调整。练习操作区固定，下面的句子列表从顶部自然显示，当前句推进到中部后才自动滚动并居中，三档提示都支持跟随。设备上已安装的指定声音会自动选用；可在“管理 → 播放与显示设置”中试听与调整。测一测只录音自查：录制期间隐藏原文和侧栏课文预览，手动背完后自动回听并显示全文，由孩子自行核对；可回听、再背一次或结束。取消文字识别与评分，不需要准备识别资源。只保留最近一份完整录音，任意课文开始新录音前删除旧文件，未完成尝试在取消或后台时清理；下次启动清理专用缓存，录音不进备份。录音、自查或清理过程中须先结束本轮才能切换功能。

构建与自动测试已经验证；指定声音、实际录音回听和锁屏连续播放仍需在目标 iPad A16 上试用。SDK 或编译成功不代替实际设备验收。

## 构建与安装

需要一台安装 **Xcode 27 或更高版本**的 Mac，以及运行 iPadOS 27 或更高版本的 iPad。Apple Pencil 默写需要兼容的 Pencil 和真机。

1. 克隆仓库，然后打开 `SimpleXue.xcodeproj`。
2. 选择 **SimpleXue** 方案，在 **Signing & Capabilities** 中选择自己的开发团队。若模块提示缺少 Team，也为该 target 选择同一团队。
3. 首次安装到自己的设备时，将 App 和模块的 Bundle Identifier 设置为自己的唯一标识；后续更新保留同一标识，以保留已有数据。
4. 选择连接的 iPad，点击运行。开发者模式、信任与签名有效期按 Xcode 和设备提示处理。

```sh
git clone https://github.com/hutianyi/simple-learn.git
cd simple-learn
open SimpleXue.xcodeproj
```

仓库提供源代码，需自行构建和签名。工程已生成，首次打开无需 XcodeGen。FSRS 依赖固定到 `4fbaf20184d62f82a9f44f343337c61a2c5483e9`；首次构建时 Xcode 可能需要联网下载依赖。

修改工程生成配置后，可在仓库根目录使用已安装的 XcodeGen：

```sh
xcodegen generate
```

生成工程后需重新选择本机开发团队。个人签名信息不应提交到仓库。

## 数据与迁移

首页右上角的“备份与恢复”可一次导出六个模块的完整备份。文件包含已保存的学习内容、记录、进度和设置，不含简单背录音、临时缓存和系统语音资源；空模块也纳入备份。完成系统“存储到文件”后才记录成功导出时间。

整体恢复先校验全部模块，再确认替换六个模块的数据和设置（包括简单背课文库）。恢复前在 `SimpleXue/WholeBackup` 保留整体安全副本；失败时自动回退。若恢复中断，下一次启动会先完成回退，再开放学习入口。回退未完成时可重试，安全副本应保留。App 本地安全副本不能替代外部导出的备份。各模块原有备份入口继续保留。

词库、题库、文章、学习进度和设置保存在设备本地。项目不提供账号系统、广告、分析服务、云同步或付费 AI API；系统语音下载及首次依赖下载可能需要网络。

原五个模块支持导出和恢复；恢复会替换对应模块数据。恢复前先结束当前学习，保存外部备份，恢复后核对记录数量、进度和设置。容器内的安全副本不能替代外部备份。

简单听可在“设置 → 备份与恢复”导出全部文章、原文、导入顺序和播放设置，恢复前需停止播放与定时。恢复会替换文章库及备份中的播放设置，并自动保留恢复前的安全副本；也兼容仅含文章库的旧内部副本。正常保存后，内部安全副本保留最近 10 份，外部导出的备份不受影响。

简单算切到后台时暂停答题计时，包括答题反馈期间自动进入下一题的情况。简单练跨天继续时，下一次复习按实际判定或完成订正的日期计算，原开题日期保留；恢复备份前会校验题号、状态、日期及记录关联，异常备份不会替换现有数据。

简单背采用追加导入：确认预览后追加新课文，重复跳过，冲突保留当前课文；备份设置仅在明确勾选时使用。备份不包含录音。

- **简单记**：使用旧 App 导出的完整 JSON 备份，在模块设置中恢复。
- **简单练**：使用旧 App 数据页导出的 JSON，在模块数据页恢复。
- **简单默／简单算**：从 Xcode 的 Devices and Simulators 下载旧 App 的 `.xcappdata` 容器，再用下列只读工具制作迁移 JSON。

以下命令在仓库根目录运行，假设容器已保存到桌面。工具读取容器并新建 JSON；同名输出已存在时拒绝覆盖。

```sh
python3 Scripts/export-legacy-data.py --module mo --container "$HOME/Desktop/简单默.xcappdata" --output "$HOME/Desktop/简单默迁移.json"
python3 Scripts/export-legacy-data.py --module suan --container "$HOME/Desktop/简单算.xcappdata" --output "$HOME/Desktop/简单算迁移.json"
```

容器和迁移文件包含个人学习数据，请存放在私人位置。迁移验收完成前保留旧 App 与备份。

## 验证

在仓库根目录运行现有核心测试。脚本在 `/private/tmp` 创建临时 Swift 包和缓存，不导入个人学习数据。

```sh
python3 Scripts/run-core-validation.py
python3 Scripts/run-listen-validation.py
python3 Scripts/run-bei-validation.py
```

核心测试覆盖导入、数据持久化、备份、复习规则、迁移与听读队列等逻辑。可用以下命令验证无签名模拟器编译：

```sh
xcodebuild -project SimpleXue.xcodeproj -scheme SimpleXue \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /private/tmp/SimpleXueOpenSourceBuild \
  CODE_SIGNING_ALLOWED=NO build-for-testing
```

运行完整 iPad 测试需要 iPadOS 27 模拟器或真机。核心测试和编译通过不能代替 Pencil 识别、系统声音、锁屏续播、Sleep Timer、横竖屏和真实备份恢复的设备验收。

## 项目结构

- `App/`：App 入口、首页、图标和配置。
- `Shared/`：模块切换、音频协调与数据迁移界面。
- `Modules/`：六个功能模块及各自测试。
- `Tests/`：共享核心测试和界面测试。
- `Scripts/`：本地验证与旧容器只读导出工具。
- `project.yml`、`SimpleXue.xcodeproj`：工程生成配置和已生成工程。
- `Attributions/`：来源说明、原许可证和接入时文件哈希。

个人开发进度、设备记录、备份和构建产物不包含在公开仓库中。
